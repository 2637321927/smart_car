# 智能车道路遥测台

这个工具在Windows电脑上接收小车UDP数据，并在浏览器中显示：

- 鸟瞰坐标下的道路左线、中线和右线。
- 当前UDP参数、速度环、方向误差、陀螺仪和超时信息。
- 红块与目标板矩形、`item_flag`和识别状态。
- 最近10秒的实际轮速、目标轮速和视觉误差趋势。
- JSONL录像、时间轴回放、逐事件查看和0.25～4倍速播放。
- 示波器与录制、载入和时间轴位于同一工作台，回放时无需来回切换区域。
- 拖动或播放时间轴时，道路线、目标框、状态摘要和UDP参数同步切换到同一时刻。
- 向小车 `8082` 端口发送现有VOFA调参命令。

## 1. 网络设置

小车使用两条相互独立的UDP目标链路：

```cpp
const std::string VOFA_TARGET_IP = "192.168.43.146";
const std::string DEBUGGER_TARGET_IP = "192.168.43.155";
```

| 接收端 | 地址 | 内容 |
|---|---|---|
| VOFA | `192.168.43.146:8080` | `#vofa=1;` 时回传参数波形，默认关闭 |
| 道路调试器 | `192.168.43.155:8080` | `udp=1/2` 时的集成示波器参数；`udp=2` 时额外包含道路三线 |
| 调试图像接收端 | `192.168.43.155:8081` | JPEG调试图像 |

运行本软件的电脑IPv4应为 `192.168.43.155`。启动软件后，控制台也会列出电脑当前可用的IPv4地址。

小车当前IP为 `192.168.43.93`，调参命令发送到：

```text
192.168.43.93:8082
```

第一次运行时，如果Windows防火墙询问Node.js网络权限，请允许专用网络访问，否则收不到小车UDP。

## 2. 启动

要求电脑安装Node.js 18或更新版本，不需要执行 `npm install`。

双击：

```text
tools\road_debugger\start_debugger.bat
```

或者在PowerShell中运行：

```powershell
cd tools\road_debugger
node server.js
```

然后打开：

```text
http://127.0.0.1:8765
```

## 3. 数据频率

先通过网页快捷按钮或VOFA命令选择发送内容：

| 命令 | 行为 |
|---|---|
| `#udp=0;` | 关闭参数和道路调试UDP，比赛时推荐 |
| `#udp=1;` | 向道路调试器发送12ms参数波形 |
| `#udp=2;` | 向道路调试器发送参数波形和道路左/中/右三线，默认模式 |
| `#vofa=0;` | 停止向 `192.168.43.146:8080` 回传波形，默认状态 |
| `#vofa=1;` | 临时向 `192.168.43.146:8080` 回传传统VOFA波形 |

小车始终在自身 `8082` 端口非阻塞接收指令。关闭 `#vofa` 只停止小车向 `.146` 回传波形，不影响 `.146` 上的VOFA继续向小车发送调参、发车和停车指令。

| 数据 | 频率 | 说明 |
|---|---:|---|
| 参数JSON | 12ms | 保留原有 `udp_timer` |
| 道路三线 | 每个新图像帧，最短间隔12ms | 相机为60FPS，实际通常约16.7ms或由图像处理耗时决定 |
| 趋势图 | 跟随参数JSON | 浏览器只保留最近10秒 |

道路帧不会发送JPEG，只发送最多 `64×3` 个鸟瞰坐标点，完整UDP包约820字节，不会超过常见1500字节MTU。

## 4. 录制与回放

点击“开始录制”后，服务器把参数事件和道路帧分别写入：

```text
tools/road_debugger/recordings/*.jsonl
```

停止录制后，在录像列表中点击“刷新”和“载入”，即可使用时间轴、单步和倍速播放。回放不会向小车发送任何命令。

## 5. 调参命令

输入框接受现有VOFA命令，例如：

```text
#P=300;
#I=10;
#spd=20;
#AIM=0.30;
#run=1;
#run=0;
```

网页只是通过UDP转发命令，小车端仍使用 `main.cpp` 中原来的命令解析逻辑。

## 6. 自检

```powershell
cd tools\road_debugger
npm run check
```

该命令检查Node.js语法并验证 `RDL1` 二进制道路帧解析。
