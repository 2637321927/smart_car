# 绕行方案三：六次手推示教轨迹

## 1. 结论

方案三不是按时间复刻手推速度，而是从最近六个录像中提取：

```text
编码器积分距离 s
+ 陀螺仪积分航向 yaw
-> 得到 yaw_ref(s)
-> 航向外环
-> 角速度内环
-> 左右轮差速
```

因此实车速度可以修改，轨迹形状仍主要由行驶距离决定。方案三与原有方案并列：

| `dbMode` | 方案 | 控制方式 |
|---:|---|---|
| `0` | 三阶段角度闭环 | 固定阶段目标角度 |
| `1` | 边线瞄准500ms | 相机边线/中线控制 |
| `2` | 六次示教轨迹 | 距离索引目标航向曲线 |

## 2. 数据来源

使用`tools/road_debugger/recordings`中时间最新的六个录像：

| 录像 | 有效路程 | 最大向外航向 | 最大航向位置 |
|---|---:|---:|---:|
| `20260725_212409_tuning.jsonl` | `0.896m` | `9.0deg` | `0.145m` |
| `20260725_212400_tuning.jsonl` | `0.839m` | `9.0deg` | `0.118m` |
| `20260725_212352_tuning.jsonl` | `0.845m` | `10.2deg` | `0.152m` |
| `20260725_212340_tuning.jsonl` | `0.968m` | `10.2deg` | `0.165m` |
| `20260725_212329_tuning.jsonl` | `0.963m` | `9.5deg` | `0.196m` |
| `20260725_212316_tuning.jsonl` | `1.093m` | `10.5deg` | `0.371m` |

六次有效路程平均值为`0.934m`，中位数为`0.963m`，所以方案三默认总路程取`0.96m`。

## 3. 提取方法

1. 只读取录像中的`params`事件，不使用脚本原有目标值。
2. 左右轮平均绝对速度超过`0.8RPS`后视为开始手推。
3. 使用开始运动前最多30个样本估计陀螺仪零偏。
4. 使用真实UDP时间差对`gyro_dps`做梯形积分，得到航向。
5. 使用左右编码器速度和`1RPS=0.047m/s`积分得到行驶距离。
6. 按最大向外航向的符号把三次左绕和三次右绕镜像到同一方向。
7. 将每次轨迹按总路程归一化，在每10%路程处取样并求平均。

这种方法学习的是空间轨迹，不是手推时快慢不均匀的时间节奏。

## 4. 学到的航向曲线

正角度表示向绕行侧偏出，负角度表示反向回到赛道并让车头略朝赛道内侧。

| 路程进度 | 平均目标航向 | 六次标准差 |
|---:|---:|---:|
| `0%` | `0.00deg` | `0.00deg` |
| `10%` | `+7.26deg` | `2.22deg` |
| `20%` | `+9.38deg` | `0.64deg` |
| `30%` | `+8.14deg` | `1.24deg` |
| `40%` | `+5.18deg` | `0.80deg` |
| `50%` | `+1.85deg` | `2.12deg` |
| `60%` | `-1.11deg` | `1.51deg` |
| `70%` | `-4.98deg` | `1.29deg` |
| `80%` | `-6.41deg` | `1.29deg` |
| `90%` | `-5.34deg` | `2.31deg` |
| `100%` | `-3.55deg` | `2.66deg` |

代码在相邻点之间做线性插值，不会每10%路程阶跃改变目标角度。左绕和右绕使用同一张表并自动镜像。

末端保留约`3.55deg`的赛道内侧预偏，而不是强制回到零。这与示教录像以及“交还巡线前让车头略朝赛道”的目标一致。

## 5. 实车控制链路

```text
识别和主动制动完成
-> 锁存dbMode=2
-> 锁存目标位置处赛道切线
-> LEARNED_PATH
-> 编码器累计当前轨迹路程
-> 查表并插值得到相对航向
-> 航向外环输出目标角速度
-> 现有角速度内环输出左右轮差速
-> 到达总路程且航向稳定
-> 中线有效：立即恢复正常巡线
-> 中线无效：进入原有RECOVER_CENTER_LINE丢线保护
```

如果`目标距离+安全余量`大于配置的示教总路程，代码会自动拉伸距离轴，避免尚未越过目标板就结束轨迹。

## 6. 调试参数

| 命令 | 默认值 | 作用 |
|---|---:|---|
| `#dbMode=2;` | `0` | 选择方案三 |
| `#dbLearnRps=15;` | `15RPS` | 整条示教轨迹的基准速度 |
| `#dbLearnDist=0.96;` | `0.96m` | 示教轨迹总路程 |
| `#dbLearnScale=1.0;` | `1.0` | 整张航向表的角度倍率 |
| `#dbHKp=8;` | `8` | 航向外环P |
| `#dbHKd=0.2;` | `0.2` | 航向外环D |
| `#dbHMax=200;` | `200dps` | 最大目标角速度 |
| `#dbYawSign=-1;` | `-1` | 实车航向符号 |

## 7. 第一轮测试

先在Debugger第三行选择“六次示教”，然后使用TEST绕行分别测试左右两侧。

```text
#dbMode=2;
#dbLearnRps=15;
#dbLearnDist=0.96;
#dbLearnScale=1.0;
#dbTestDist=0.50;
#test_driveby=0;
```

右绕只需改为：

```text
#test_driveby=2;
```

重点观察现有UDP曲线：

| 字段 | 预期现象 |
|---|---|
| `drive_state` | 进入`LEARNED_PATH` |
| `drive_phase_distance_m` | 从`0`连续增加到约`0.96m` |
| `drive_target_yaw_deg` | 平滑向外、过零、反向回赛道 |
| `drive_yaw_deg` | 能跟随目标航向且没有明显滞后 |
| `drive_target_yaw_rate_dps` | 不应长期顶在`dbHMax` |
| `drive_turn_rps` | 不应长期顶在角速度环差速上限 |

第一轮只调整一个变量：

| 现象 | 优先调整 |
|---|---|
| 整体横移不够 | 增大`dbLearnScale`，例如`1.10` |
| 整体横移过大 | 减小`dbLearnScale`，例如`0.90` |
| 轨迹形状正确但结束过早 | 增大`dbLearnDist` |
| 轨迹形状正确但结束过晚 | 减小`dbLearnDist` |
| 航向跟不上目标 | 先降低`dbLearnRps`，再检查航向环参数 |

## 8. 安全边界

- 方案三默认关闭，只有`dbMode=2`并进入绕行时执行。
- 普通巡线、方案一和方案二不读取这张示教表。
- 陀螺仪未准备好或数据过期时沿用现有停车保护。
- 轨迹超过4秒或超过计划路程额外`0.50m`时停车。
- K2、停车按钮和`#run=0;`保持最高优先级。
- 实车效果仍需要LoongArch目标编译和场地测试确认。
