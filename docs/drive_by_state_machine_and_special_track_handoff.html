一、核心结论

当前实现 目标板绕行拥有高于十字和环岛的优先级。远距离红块候选一旦确认，十字和环岛状态会被清零，直到绕行结束后再等待固定300ms才恢复检测。
主要风险 车辆恢复35RPS后，300ms约前进49cm。如果目标板后紧跟十字或环岛，车辆可能已经越过最明显的入口特征，最终按普通巡线冲入特殊路段。
建议方向 不要简单取消300ms保护，而应增加一个低速的交接状态：绕行后先以约15RPS运行，提前观察并锁存十字/环岛候选；候选稳定后直接移交特殊路段状态机，无候选时再恢复35RPS。

四、当前十字与环岛状态

十字状态机

CROSS_NONE
→ CROSS_BEGIN：同时发现左右L角点
→ CROSS_IN：角点接近车身或近线不足
→ CROSS_NONE：远线重新恢复

十字进入后使用远线控制。主循环先检查十字，十字成立时会清除环岛状态，因此十字优先级高于环岛。

环岛状态机

CIRCLE_NONE
→ LEFT/RIGHT_BEGIN
→ LEFT/RIGHT_IN
→ LEFT/RIGHT_RUNNING
→ LEFT/RIGHT_OUT
→ LEFT/RIGHT_END
→ CIRCLE_NONE

入口判断依赖“单侧L角点+另一侧长直线”；环内阶段通过左右线丢失/恢复和编码器里程切换。

五、目标板后紧接十字或环岛的风险

5.1 当前交接顺序

目标板候选确认
→ drive_by_busy = true
→ 每帧清空十字/环岛状态
→ 完成绕行并立即恢复35RPS
→ 继续屏蔽特殊路段300ms
→ 300ms后重新执行十字/环岛检测

35RPS × 0.047m/s/RPS × 0.300s ≈ 0.49m

也就是说，恢复特殊路段检测前车辆大约已经前进49cm。这个距离足以让十字L角点或环岛入口角点离开有效识别区域。

场景可能发生的情况后果
绕行后紧接十字左右L角点在300ms屏蔽期内出现并消失无法进入CROSS_BEGIN，车辆按普通中线高速通过
绕行后紧接环岛单侧L角点和对侧长直线入口特征被错过无法进入环岛状态机，可能直接切入环内错误路线
红块出现时已经进入特殊路段目标板状态机清空现有十字/环岛状态原特殊路段进度丢失，瞄准线恢复为普通中线
绕行残缺边线被立即识别如果简单删除300ms屏蔽，残缺边线可能被当成L角点误触发十字或环岛

六、建议增加低速特殊路段交接状态

建议在绕行完成和恢复普通35RPS之间增加：

TURN_TO_TRACK / RECOVER_CENTER_LINE
→ POST_DRIVEBY_HANDOFF
→ CROSS_BEGIN / CIRCLE_*_BEGIN / IDLE
项目建议初值目的
交接基准速度15RPS降低漏判后冲入特殊路段的风险
最大交接时间200ms15RPS下约前进14cm，明显小于当前49cm
候选确认最近3帧中命中2帧过滤绕行后残缺边线造成的单帧误判
普通巡线恢复中线连续有效3帧且无特殊候选确保车身已经重新稳定落在道路上
检测优先级十字优先、环岛其次、普通巡线最后保持现有特殊路段判定顺序

6.1 被动观察与正式接管必须分离

从TURN_TO_TRACK后半段开始，可以利用每帧已经计算出的左右线和L角点，被动记录以下候选：

  • 左右L角点同时稳定出现：十字候选。
  • 左L角点+右侧长直线：左环岛候选。
  • 右L角点+左侧长直线：右环岛候选。

此时只保存候选类型、方向和连续次数，不允许特殊路段状态机改写瞄准线。等绕行航向闭环正式结束，再移交控制权。

6.2 推荐交接判断

进入 POST_DRIVEBY_HANDOFF
→ 基准速度保持15RPS
→ 普通中线方向环继续工作

若十字候选达到2/3帧：
    进入 CROSS_BEGIN

否则若左/右环岛候选达到2/3帧：
    进入对应 CIRCLE_LEFT_BEGIN / CIRCLE_RIGHT_BEGIN

否则若中线连续有效3帧且没有特殊候选：
    恢复35RPS，进入IDLE

若200ms结束仍丢线：
    不得直接恢复35RPS，继续低速找线或安全停车
不建议仅把300ms改成0。绕行刚结束时左右边线通常不完整，直接开放十字/环岛判断会增加误触发。低速交接和多帧确认可以同时解决“漏判”和“误判”。

七、边界情况和优先级建议

情况建议处理原因
绕行已经开始，随后看到十字/环岛绕行继续执行；只被动锁存特殊候选，完成后再交接避免两个状态机同时改写瞄准线和左右轮目标
十字/环岛已经进入，随后看到红块特殊路段优先，暂不触发目标板绕行当前绕行脚本以局部固定航向为参考，不能安全继承环岛或十字进度
同一帧同时出现红块和特殊路段入口已激活的状态优先；都未激活时先降低速度，再根据连续多帧结果仲裁单帧无法可靠判断哪个目标在物理位置上更靠前
目标板位于环岛内部当前版本不建议执行目标板绕行需要保留环岛切线、环岛阶段和沿曲线的航向参考，属于组合状态机改造
交接阶段陀螺仪异常普通视觉中线低速接管；若持续丢线则停车不能在航向数据失效时盲目进入转向型特殊路段
建议实施顺序： 先增加POST_DRIVEBY_HANDOFF和15RPS低速交接；再加入十字/环岛候选锁存；最后用“目标板后紧接十字”和“目标板后紧接左右环岛”三种实车布局验证。不要第一步就设计环岛内部绕障。
