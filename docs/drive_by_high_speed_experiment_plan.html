1. 任务目标

改造前的历史流程为：

检测到红色
→ 停车约 200ms
→ 停车状态下完成多帧推理
→ 按固定轮速、固定时间执行绕行
→ 恢复巡线

当前实现流程为：

35RPS 正常巡线
→ 只执行低负担红色检测
→ 检测到红色后才启动 NCNN
→ 远距候选成立后主动制动，释放后以 0RPS 基准识别
→ 三帧投票完成且制动完成后按dbMode进入所选绕行方案
→ dbMode=0：三阶段角度闭环，第二转完成后恢复巡线
→ dbMode=1：按dbSideMs定时瞄准边线，切回中线并在中线恢复后恢复巡线
dbMode=0默认速度为0/10/10RPS；dbMode=1使用dbForwardRps=10RPS。实测换算采用1RPS≈0.047m/s。

3. 识别与性能策略

3.1 无红色时不运行 NCNN

K0 关闭
→ 不检测红色，不运行 NCNN

K0 开启、没有红色
→ 每 2 帧对裁剪后的识别区域做一次 HSV 红色检测
→ 不调用 NCNN

确认检测到红色
→ 提取目标 ROI
→ 主动制动释放后把基准速度设置为 0RPS
→ 判断目标板观察角度
→ 观察角度合适时才提交 NCNN

红色检测只处理有效裁剪区域，不对整幅 320×240 图像执行完整 HSV、形态学和轮廓搜索。

3.2 未来异步推理策略

  • worker 空闲时接收一张新的 ROI。
  • worker 正在推理时跳过当前帧，不积压过期图像。
  • 获取 3 个不同有效帧后停止该目标的所有后续推理。
  • 2:1 或 3:0 采用多数结果。
  • 1:1:1、超时或不足 3 帧时按直行处理。
  • worker 无任务时通过条件变量休眠。
当前代码采用同步三帧投票；若前两帧有效结果一致，会直接形成多数票并提前结束。识别期间保持0RPS基准和普通方向环，因此仍可能通过左右反向差速原地修正车头。

持续刹车测试使用#test_brake=1;开启、#test_brake=0;关闭。它复用相同的远距候选、严格红块确认和投票流程；第一票候选先以0RPS基准进行速度闭环预减速，第二票确认后再输出-9000 PWM主动制动。制动达到dbBrakeRelease后保持零PWM等待识别结束，随后直接停车，不进入绕行。开关会跨停车保持。主动制动专用PWM范围为0至9000，默认9000；普通反向输出仍限制为4000。

4. 目标位置、切线与车板连线

目标板法向与目标所在位置的赛道切线平行，但在弯道上，小车到目标板的连线通常不平行于赛道切线。

车辆到目标板的连线 ≠ 目标位置处赛道切线
几何量计算来源用途
车辆到目标板连线目标与车辆的相对位置判断目标在哪一侧、计算观察夹角
目标位置处赛道切线目标附近的鸟瞰中线判断目标板法向和绕行方向
车辆当前航向本次绕行的陀螺仪积分判断车辆实际转过多少角度

4.1 目标地面位置

红块底边基本接触地面，计划使用红块底边中心：

target_ground_pixel =
(red_center_x, red_bottom_y)

通过现有 mapx/mapy 逆透视表映射到鸟瞰坐标，再寻找最近的赛道中线点，得到 target_track_index 和 target_along_track_distance。后者是沿赛道中线的距离，不是相机到目标板的空间直线距离。

4.2 目标位置处切线

在目标中线索引前后约 0.10m 的点上做小规模直线拟合，得到 target_track_heading。运算只涉及约 10 个点的乘加和一次角度计算，且只在发现红色后运行，开销远小于图像处理和推理。

4.3 观察夹角

view_angle =
目标板法向 与 目标板到车辆连线 的夹角

未来计划只在 view_angle <= 46° 且 ROI 完整时提交推理。该阈值需由明日实验验证。

5. 有限时域陀螺仪与编码器积分

5.1 积分生命周期

正常巡线：
drive_by_yaw_deg 不累计
drive_by_distance_m 不累计

目标会话开始：
drive_by_yaw_deg = 0°
drive_by_distance_m = 0m
phase_distance_m = 0m
记录赛道切线和目标沿线距离
清空角速度内环积分

绕行每个控制周期：
drive_by_yaw_deg += gyro_dps × dt
drive_by_distance_m += 平均编码器RPS × db_rps_to_mps × dt

第二转完成：
恢复正常视觉巡线和 35RPS
停止并丢弃本次两项积分

一次三阶段绕行预计持续约 1～2s。陀螺仪积分在有限时域内是重要的连续姿态数据，但不会在正常巡线中无限累计。

5.2 陀螺仪与视觉赛道方向融合

vehicle_yaw = drive_by_yaw_deg
dbUseTangent=1: track_heading = vehicle_yaw + track_relative_heading
dbUseTangent=0: track_heading = 脚本启动时的vehicle_yaw
desired_vehicle_yaw = track_heading + 当前阶段横移偏角
heading_error = desired_vehicle_yaw - vehicle_yaw
  • 陀螺仪积分提供 8ms 级连续姿态。
  • 需要对比弯道效果时，可手动开启视觉切线参考。
  • 视觉短暂丢失时可暂时依靠陀螺仪积分。
  • 回正后丢弃积分，不产生长期漂移。

5.3 编码器比例必须实测

db_rps_to_mps = 0.047
该值来自当前定距测速，是三阶段距离积分的实测初值；更换轮胎、传动比或场地后仍应重新标定。

6. 双方案绕行状态机

#dbMode=0;选择原三阶段角度闭环，#dbMode=1;选择边线瞄准实验方案。模式在每次绕行运动开始时锁存，中途修改只影响下一次脚本。

6.1 三阶段角度闭环（dbMode=0）

目标位置处切线仍用于观察夹角和调试显示，但默认不参与绕行航向控制。#dbUseTangent=0;时以脚本启动时车头为零度；发送#dbUseTangent=1;后恢复目标处切线参考。该开关在运动开始时锁存，中途修改只影响下一次绕行。

阶段相对所选参考航向的偏角默认基准速度目的
TURN_OUT绕行侧42°0RPS原地向目标板侧方转出
PASS_SHORT继续保持绕行侧42°10RPS沿斜向轨迹越过目标板
TURN_TO_TRACK回到赛道参考航向0°10RPS反向转向并交还巡线

左右绕行完全镜像。以左绕为例，第一次目标为左偏42°，第二次回到参考航向0°，因此第二次实际反转约42°。

desired_yaw = locked_track_heading + phase_offset
target_yaw_rate = clamp(
    heading_kp * heading_error - heading_kd * gyro_dps,
    -dbHMax,
    +dbHMax)

目标角速度继续交给现有 gIP/gII/gRMax 内环产生左右轮差速。

两个转向阶段的主切换条件：
沿本阶段转动方向投影后的车头积分
>= 沿同方向投影后的目标角

旧的“航向误差进入容差且角速度稳定，连续满足3个8ms周期”
只保留为尚未越线时的兜底，不再是正常切换必须满足的条件。

PASS_SHORT必须同时满足：
phase_distance >= dbPassDist
distance_since_trigger >= target_distance + dbSafeDist

dbPassDist默认0.32m，dbSafeDist默认0m。第一次转出时，车头积分沿转出方向达到或越过dbTurnAngle就进入斜行，不再要求角速度先降到接近0。第二次转回沿回程方向达到或越过dbReturnBias后检查中线：可靠时直接恢复普通方向环；仍丢线时左绕给+dbRecoverDps、右绕给-dbRecoverDps，并保持dbExitRps直到中线恢复。旧的稳定判定只作为未越线时的兜底。默认dbRecoverDps=55dps；陀螺仪不可用时回退为±100视觉误差。交还时不恢复识别前保存的旧差速。

6.2 两套方案共用的回程丢线保护

无论选择哪套方案，回到赛道时都必须先确认中线剩余有效点不少于15点。左绕后找不到中线就给+dbRecoverDps，右绕后找不到中线就给-dbRecoverDps，默认幅值55dps，直到中线恢复。陀螺仪不可用时才回退到±100视觉误差。dbMode=0找线时保持dbExitRps，dbMode=1保持dbForwardRps。

6.3 边线瞄准实验方案（dbMode=1）

该方案保留相同的红块检测、主动制动和识别投票，只替换识别完成后的运动控制。

状态左绕右绕结束条件
FOLLOW_SIDE_LINE原始左边线作为瞄准线原始右边线作为瞄准线持续dbSideMs，默认500ms
RECOVER_CENTER_LINE切回中线，丢线时给+dbRecoverDps向右找线切回中线，丢线时给-dbRecoverDps向左找线中线剩余有效点不少于15点
完成普通中线和方向环接管普通中线和方向环接管同一个8ms周期恢复dbNormalSpd

指定边线不足3点时，左绕暂时给-100继续向左，右绕暂时给+100继续向右。强制误差仍经过现有方向环限幅和差速保护。

新方案全程采用dbForwardRps（默认10RPS）作为基准速度。它不在脚本内部使用角度和距离切换，但普通方向环仍遵守#gyro设置。

dbSideMs控制边线瞄准持续时间，默认500ms，可调范围500至2000ms。命令示例：#dbSideMs=1200;表示持续瞄准边线1.2s；越界输入会由小车端限制到最近边界。增大该值通常会增加沿边线行驶时间和横向绕出距离。FOLLOW_SIDE_LINE的安全超时为dbSideMs+500ms；为保证高dbForwardRps时也能完整执行设定时间，该阶段不使用固定距离上限。RECOVER_CENTER_LINE仍使用原来的1.5s/0.80m保护。

11. 收到数据后的计划修订

  1. 计算正式的 db_rps_to_mps。
  2. 确定35→20RPS的实际响应时间和距离。
  3. 判断当前红色检测距离是否满足高速提前量。
  4. 判断 3 帧投票在不同观察角度下是否可靠。
  5. 确定最大允许推理观察夹角。
  6. 确定最短斜行距离和目标后安全余量。
  7. 判断直道与缓弯是否能共用同一最大偏角。
  8. 评估陀螺仪在 1～2 秒内的积分误差。
  9. 验证横向偏移后视觉中线是否仍能提供切线。
  10. 根据实测数据生成最终代码实施计划和分阶段验收标准。
