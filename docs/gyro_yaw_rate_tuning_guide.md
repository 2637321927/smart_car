# 角速度环调参上手手册：从赛道现象理解参数

> 这份文档不是单纯解释每个变量，而是按真实跑车时会遇到的场景讲：直道、入弯、弯中、出弯、高速转不动、左右震荡时，各个参数到底在配合做什么。  
> 当前实车结论：`gSign=-1` 后角速度反馈方向正确；`tSign=1` 使用默认值；`gII=0` 先关闭积分。

## 1. 先建立直觉

角速度环不是让小车“直接按 error 打轮”，而是让小车按一个目标旋转速度去转。

```text
视觉 error
    -> 判断我现在偏了多少
    -> 外环 gOP/gOD 算出我希望车头转多快，也就是 gyro_target_dps
    -> MPU6050 测出车头实际转多快，也就是 gyro_dps
    -> 内环 gIP/gII 算出左右轮差速
    -> 速度环让左右轮执行这个差速
```

所以调参时不要只问“P 是多少”，要问：

```text
现在这辆车是在直道轻微纠偏，还是刚入弯，还是弯中转不够，还是出弯回正太慢？
```

不同场景下，同一个参数的意义不一样。

## 2. 当前默认值

| 参数 | 当前默认值 | VOFA 命令 | 一句话作用 |
|---|---:|---|---|
| 角速度环开关 | `1` | `#gyro=0;` / `#gyro=1;` | 默认打开；需要回到旧视觉 PD 时发 `#gyro=0;` |
| `gSign` | `-1` | `#gSign=-1;` | 修正 MPU6050 角速度正负方向 |
| `tSign` | `1` | `#tSign=1;` | 修正左右轮差速输出方向 |
| `gOP` | `1.4` | `#gOP=1.4;` | error 越大，想转得越快 |
| `gOD` | `0.15` | `#gOD=0.15;` | error 变化快时提前给转向需求 |
| `gIP` | `0.055` | `#gIP=0.055;` | 实际角速度跟不上目标时，给更多差速 |
| `gII` | `0.0` | `#gII=0;` | 长期转不够时慢慢补偿，先关闭 |
| `gyro_target_max_dps` | `160` | `#gTMax=160;` | 限制外环最多想让车转多快 |
| `gyro_turn_max_rps` | `15` | `#gRMax=15;` | 限制内环最多给多少左右轮差速 |
| `spd_slow_ratio` | `20` | `#spd_slow_ratio=20;` | error 越大，基础速度越低 |

当前建议起步命令：

```text
#gyro=1;
#gSign=-1;
#tSign=1;
#gOP=1.4;
#gOD=0.15;
#gIP=0.055;
#gII=0;
#gTMax=160;
#gRMax=15;
#spd_slow_ratio=20;
```

## 3. 一次过弯里，参数分别在干什么

把一个弯拆成 4 个阶段，会比死记参数更好理解。

| 阶段 | 车的状态 | 主要参数 | 参数在做什么 |
|---|---|---|---|
| 入弯前 | 视觉 error 开始变大 | `gOD`、`gOP` | 提前意识到“要转了”，让目标角速度开始变大 |
| 刚入弯 | error 已经明显偏离 | `gOP`、`spd_slow_ratio` | 决定目标角速度够不够，以及要不要降速 |
| 弯中 | 车要持续旋转 | `gIP`、`gyro_turn_max_rps` | 让实际 `gyro_dps` 跟住目标 `gyro_target_dps` |
| 出弯 | error 开始回小 | `gOD`、`gII` | 避免继续转过头，让车头及时收回来 |

### 3.1 入弯前：车要不要“提前有反应”

入弯前通常是这样的：

```text
latest_error 原来很小
突然开始变大
```

这时候 `gOD` 会发挥作用。它看的是 error 的变化速度，而不只是 error 的大小。

| 现象 | 可能含义 | 调参方向 |
|---|---|---|
| 入弯明显慢半拍 | `gOD` 太小，或者 `gOP` 太小 | 小幅加 `gOD` 或 `gOP` |
| 刚看到弯就猛抖一下 | `gOD` 太大，对视觉跳变太敏感 | 降 `gOD`，甚至先设 `0` |
| 直道上 error 有噪声，target_dps 也乱跳 | `gOD` 放大了视觉噪声 | 降 `gOD` |

入弯前的参数配合：

| 参数组合 | 效果 |
|---|---|
| 高 `gOD` + 高 `gOP` | 反应快，但很容易神经质 |
| 低 `gOD` + 中等 `gOP` | 稳，但入弯可能慢 |
| `gOD=0` + 调 `gOP/gIP` | 适合先确认基础闭环方向和强度 |

调参建议：

```text
如果车刚入弯慢，可以先加 gOP。
如果加 gOP 后直道也开始晃，再考虑小加 gOD，而不是猛加。
```

### 3.2 刚入弯：目标角速度够不够

刚入弯时，视觉 error 已经比较明显。此时外环会算：

```text
gyro_target_dps = gOP * error + gOD * error变化量
```

`gOP` 决定“偏这么多，我到底想让车转多快”。

| 看到的现象 | 看 UDP 哪个量 | 判断 |
|---|---|---|
| 高速弯转不进去，`gyro_target_dps` 也不大 | `gyro_target_dps` | 外环要求太弱，加 `gOP` |
| 高速弯转不进去，但 `gyro_target_dps` 已经很大 | `gyro_target_dps`、`gyro_dps` | 不是外环问题，可能内环或速度问题 |
| 一入弯 target_dps 打满，车还乱 | `gyro_target_dps` | 外环太激进，降 `gOP/gOD` |

调参建议：

| 目的 | 操作 |
|---|---|
| 入弯更积极 | `gOP` 从 `1.4` 加到 `1.6` |
| 入弯更稳 | `gOP` 从 `1.4` 降到 `1.2` |
| 暂时排除 D 的干扰 | `#gOD=0;` |

### 3.3 弯中：实际角速度能不能跟上

弯中最关键的是比较这两个量：

```text
gyro_target_dps：希望车转多快
gyro_dps：车实际转多快
```

如果目标是 `100 deg/s`，实际只有 `50 deg/s`，说明车转不够。内环会用 `gIP` 给更多差速。

| 现象 | 可能含义 | 调参方向 |
|---|---|---|
| `gyro_target_dps` 很大，`gyro_dps` 跟不上 | 内环不够硬，或车速太高 | 加 `gIP` 或加 `spd_slow_ratio` |
| `gyro_dps` 一下超过目标很多 | 内环太硬 | 降 `gIP` |
| `ex_rps1/ex_rps2` 经常顶到差速限幅 | 已经给满差速但仍转不够 | 不要只加 PID，应该降速或提高机械转向能力 |

弯中参数配合：

| 参数 | 它解决的问题 |
|---|---|
| `gIP` | 目标角速度和实际角速度之间的即时差距 |
| `spd_slow_ratio` | 高速下轮胎/电机转不过来时，通过降速降低转弯难度 |
| `gyro_turn_max_rps` | 差速最大允许值，可用 `#gRMax=15;` 在线修改 |

调参建议：

```text
如果高速转不动，先看 gyro_target_dps 和 gyro_dps。
target 不大，加 gOP。
target 很大但 gyro 跟不上，加 gIP 或加 spd_slow_ratio。
```

### 3.4 出弯：能不能及时收住

出弯时 error 应该逐渐变小，目标角速度也应该回到 0 附近。

| 现象 | 可能含义 | 调参方向 |
|---|---|---|
| 出弯后还继续转 | `gOP/gIP` 太大，或 `gII` 有积累 | 降 `gIP`，保持 `gII=0` |
| 出弯左右摆两下 | 外环和内环都偏硬 | 降 `gOP` 或 `gIP` |
| 出弯回正慢 | 整体控制偏软 | 小加 `gIP`，必要时小加 `gOP` |

现在我们建议 `gII=0`，就是为了减少出弯拖尾。积分虽然能补“长期转不够”，但也最容易让车出弯后还带着一股劲继续转。

## 4. 按现象调参

### 4.1 低速正常，高速转不动

这是你们当前最典型的现象。

| 先看 | 如果是这样 | 怎么调 |
|---|---|---|
| `gyro_target_dps` | 高速入弯时目标角速度不高 | 加 `gOP` |
| `gyro_dps` | 目标很高，但实际跟不上 | 加 `gIP` |
| `ex_rps1/ex_rps2` | 差速已经很大甚至接近限幅 | 加 `spd_slow_ratio`，不要只加 PID |
| 车速 | 入弯速度明显过高 | 加 `spd_slow_ratio` |

推荐顺序：

```text
第一步：#spd_slow_ratio=30;
第二步：#gOP=1.6;
第三步：#gIP=0.065;
```

不要三个一起改。每次只改一个，跑一圈看变化。

### 4.2 直道左右摇头

直道摇头通常不是“转向不够”，而是“对小 error 太敏感”。

| 现象 | 可能原因 | 调参方向 |
|---|---|---|
| `latest_error` 小幅抖，`gyro_target_dps` 跟着抖 | 外环太敏感 | 降 `gOP/gOD` |
| `gyro_target_dps` 不大，但 `ex_rps1/ex_rps2` 抖 | 内环太硬 | 降 `gIP` |
| 开 `gOD` 后更抖 | D 放大视觉噪声 | 降 `gOD` 或设 0 |

推荐回退：

```text
#gOD=0;
#gOP=1.2;
#gIP=0.045;
```

### 4.3 车头收敛到正确方向很慢

这个现象一般说明控制整体偏软。

| 场景 | 优先参数 |
|---|---|
| `spd=0` 原地验证时收敛慢 | 小加 `gIP` |
| 低速跑车时入弯慢 | 小加 `gOP` |
| 高速弯中跟不上 | 小加 `gIP` 或加 `spd_slow_ratio` |

注意：`spd=0` 只能短时间验证方向，不适合判断巡线稳定性。

### 4.4 一有 error 就开始原地转

如果 `spd=0`，这很正常。因为差速车公式是：

```text
ex_rps1 = base_rps + turn_rps
ex_rps2 = base_rps - turn_rps
```

当 `base_rps=0`：

```text
ex_rps1 = +turn_rps
ex_rps2 = -turn_rps
```

一个轮子正转，一个轮子反转，就是原地转。

| `spd=0` 适合做什么 | `spd=0` 不适合做什么 |
|---|---|
| 看 `gSign/tSign` 方向是否对 | 判断巡线稳定性 |
| 看车头能不能大致朝正确方向收敛 | 判断高速过弯能力 |
| 短时间测试角速度反馈 | 判断直道摇头 |

### 4.5 超时偶尔出现

你们实测大约 3 分钟 8 次超时，这个数量可以先观察，不是当前主矛盾。

| 现象 | 处理 |
|---|---|
| `gyro_timeout` 偶尔增加 | 记录即可，先继续调车 |
| `gyro_read_ms` 平时约 `0.2~1ms`，偶尔大 | 属于偶发调度/I2C卡顿 |
| `gyro_timeout` 快速连续增加 | 先别加大 PID，检查负载、I2C、日志输出 |
| `gyro_dps` 很久不刷新 | 当前反馈不可靠，应先解决读取问题 |

## 5. 参数之间的配合关系

### 5.1 `gOP` 和 `gIP` 的配合

这两个参数经常要一起看。

| 组合 | 车的感觉 |
|---|---|
| `gOP` 大、`gIP` 小 | 目标喊得很凶，但车实际跟不上，弯中拖 |
| `gOP` 小、`gIP` 大 | 目标不激进，但一点误差也会被内环硬修，可能抖 |
| `gOP` 大、`gIP` 大 | 入弯很猛，容易高速震荡或打满差速 |
| `gOP` 中等、`gIP` 中等 | 最适合先找稳定基础 |

调参顺序：

```text
先用 gOP 决定“想转多快”
再用 gIP 决定“能不能跟上这个目标”
```

### 5.2 `gOD` 和视觉 error 的关系

`gOD` 不适合在视觉 error 很抖时开太大。

| error 质量 | `gOD` 建议 |
|---|---|
| error 很平滑 | 可以小加 |
| error 偶尔跳变 | 少加或不加 |
| error 经常从几十跳到 ±100 | 先设 0 |

简单说：

```text
gOD 不是越大越高级。
图像误差不干净时，D 会把不干净的地方放大。
```

### 5.3 `spd_slow_ratio` 和 PID 的关系

高速转不动时，不一定是 PID 不够。有时候是速度太高，轮子没有足够时间和抓地去完成转向。

| 做法 | 优点 | 风险 |
|---|---|---|
| 加 `gOP/gIP` | 转向更积极 | 直道可能抖，高速可能打满 |
| 加 `gTMax/gRMax` | 放开目标角速度或差速限幅 | 过大时容易猛打和震荡 |
| 加 `spd_slow_ratio` | 弯中更容易转进去 | 速度会下降 |
| 两者都加 | 过弯能力增强 | 容易过猛，需要小步试 |

建议：

```text
高速弯转不动时，优先试 spd_slow_ratio=30。
如果降速后还是转不动，再加 gOP/gIP。
```

### 5.4 为什么 `gII` 先不要急着加

积分适合解决“长期差一点”的问题，不适合解决方向错误或基础参数没调好。

| 当前阶段 | `gII` 建议 |
|---|---|
| 还在确认方向 | 必须 0 |
| 直道还会晃 | 先不要加 |
| 高速弯总是差一点点，且不震荡 | 可以试 `0.002~0.006` |
| 出弯拖尾 | 立刻降回 0 |

## 6. 推荐调参路线

### 6.1 方向确认阶段

```text
#gyro=1;
#gSign=-1;
#tSign=1;
#gOD=0;
#gII=0;
#spd=3;
```

| 目标 | 判断 |
|---|---|
| 确认不会越修越偏 | `gyro_dps` 应逐渐向 `gyro_target_dps` 靠近 |
| 确认差速方向正确 | 车偏了以后应往回修 |
| 确认基础闭环不炸 | `ex_rps1/ex_rps2` 不应长期疯狂打满 |

### 6.2 基础稳定阶段

```text
#gOP=1.2;
#gIP=0.045;
#gOD=0;
#gII=0;
```

如果稳定，再走向当前默认：

```text
#gOP=1.4;
#gIP=0.055;
#gOD=0.15;
```

### 6.3 高速增强阶段

如果低速已经稳定，高速弯转不动：

```text
#spd_slow_ratio=30;
```

如果还不够：

```text
#gOP=1.6;
```

如果 `gyro_target_dps` 已经高但 `gyro_dps` 跟不上：

```text
#gIP=0.065;
```

### 6.4 收尾优化阶段

只有车已经稳定，才试：

```text
#gII=0.002;
```

如果出现出弯拖尾、直道慢慢偏、或者震荡变多：

```text
#gII=0;
```

## 7. 快速诊断表

| 车的表现 | 看哪个量 | 最可能原因 | 优先动作 |
|---|---|---|---|
| 一开角速度环越修越偏 | `gyro_target_dps` 和 `gyro_dps` 方向 | `gSign/tSign` 错 | 先查 `gSign`，再查 `tSign` |
| 低速好，高速弯转不动 | `gyro_target_dps`、`gyro_dps` | 目标不够或跟不上 | 加 `spd_slow_ratio`，再调 `gOP/gIP` |
| 直道左右摆 | `latest_error`、`gyro_target_dps` | 外环太敏感 | 降 `gOP/gOD` |
| 目标不大但轮速抖 | `ex_rps1/ex_rps2` | 内环太硬 | 降 `gIP` |
| 入弯慢 | `gyro_target_dps` | 外环太软 | 加 `gOP`，必要时小加 `gOD` |
| 出弯拖尾 | `gyro_turn_rps`、`gII` | 积分或内环太强 | 降 `gII/gIP` |
| 偶发超时 | `gyro_timeout`、`gyro_read_ms` | 读取偶发卡顿 | 先记录，别急着改 PID |
| 连续超时 | `gyro_timeout` 快速增长 | 读取链路不稳 | 暂停调 PID，查 I2C/负载 |

## 9. 调参口诀

```text
先看方向，再调强度。
先关积分，再找 P。
入弯慢看 gOP/gOD。
弯中跟不上看 gIP 和降速。
直道抖先降 gOD，再降 gOP/gIP。
高速转不动，不要只怪 PID，先考虑 spd_slow_ratio。
```
